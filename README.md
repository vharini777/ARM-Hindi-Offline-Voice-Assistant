# 🎙️ Offline Hindi Voice Assistant (Raspberry Pi)

A fully offline, privacy-preserving Hindi voice assistant running entirely on a Raspberry Pi 4.  
All speech processing is performed locally with **no cloud dependency**, ensuring low latency and complete privacy.

---

## 🚀 Features

- 🔊 Hindi Speech-to-Text (ONNX-optimized Wav2Vec2)
- 🎯 Lightweight Intent Recognition (Fuzzy Matching)
- 🗣️ Offline Text-to-Speech (eSpeak NG)
- ⚡ Energy-Based Voice Detection
- 🧵 Multithreaded Non-Blocking Responses
- 🌐 100% Offline Operation

---

## 🧠 Architecture

Microphone → Voice Detection → ONNX ASR → Intent Detection → Action → TTS → Speaker
